# LocalTuristico

Site desenvolvido para apresentar pontos turísticos e locais de interesse de uma cidade ou região, facilitando que visitantes e moradores conheçam melhor os lugares disponíveis.

## Sobre o projeto

O objetivo do LocalTuristico é reunir em um só lugar informações sobre atrações locais, ajudando o usuário a descobrir opções de passeio de forma simples e organizada.

## Tecnologias utilizadas

- HTML5
- CSS3
